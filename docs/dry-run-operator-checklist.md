# Model Studio dry-run operator checklist

> FICTIONAL — TEST DATA — NOT FOR CONSTRUCTION

Use with the detailed [dry-run SOP](dry-run-sop.md). A checked box requires evidence; it is not a claim of professional, survey, permit, capacity, code, or construction readiness.

## Before the run

- [ ] Case ID, matrix reason, source type, geometry/system coverage, and operator recorded.
- [ ] Source is authorized and contains no unrelated private data.
- [ ] Filename, pages/bytes, citation, source revision/date, and SHA-256 captured.
- [ ] Project ID, slug, canonical revision, commit, and fingerprint captured.
- [ ] CRS/units/datum/benchmark/transformations are source backed or explicitly unknown.
- [ ] Exact disclaimer is present.

## Intake and authoring

- [ ] PDF added through Model Studio; stored checksum matches source bytes.
- [ ] New intake remains `unknown` and supports no claims until reviewed.
- [ ] Stable IDs, interfaces, topology, citations, and required systems reviewed.
- [ ] Provenance uses only confirmed, reference-derived, reviewed assumption, generated, or unknown.
- [ ] Missing approvals, survey, hydraulics/capacity, ownership, and code facts remain explicit.
- [ ] Hands-on minutes and decisions recorded in **Record operator touch**.

## Run and gates

- [ ] Factory window shows intended revision, fingerprint, source locks, stage, and current action.
- [ ] One canonical run started; queued/running/completed state and automated time observed.
- [ ] Every validation issue and readiness group reviewed.
- [ ] Result classified as pass, valid fail-closed incomplete plans, pipeline defect, or not assessed.
- [ ] Review notes did not bypass a gate.
- [ ] Current fingerprint, validation, parity, schema, disclaimer, and hashes pass before publish.
- [ ] Immutable publication ID, handoff manifest, directory, and import file recorded.

## Field Map and phone

- [ ] Published manifest accepted unchanged by the read-only consumer contract.
- [ ] Correct project/revision/disclaimer visible; no cached project replaced it.
- [ ] Every expected layer toggled; phases and drawer controls remain operable.
- [ ] Representative point, line, polygon, surface, and assumption warnings inspected.
- [ ] Comparison covers boundary/constraint, building/access/interface, every available utility, drainage, and grading when scoped.
- [ ] Physical-phone evidence captured, or its absence blocks full end-to-end pass.

## Closeout

- [ ] Issues assigned S1–S4; repairs have focused, prior-fixture, full-producer, and consumer regressions.
- [ ] Operator and automated time reported separately.
- [ ] Final status and every unmet criterion/unknown stated.
- [ ] Evidence index saved; large/generated binaries remain uncommitted.
- [ ] Failed/audit/immutable evidence preserved; only disposable state cleaned.
- [ ] “100%” means all verifiable in-scope criteria plus explicit unknowns—never fabricated certainty.
